# Ozamis Autos y Motos — demo web

Demo estática, no oficial, preparada exclusivamente para Ozamis Autos y Motos, con domicilio público informado en Av. San Martín Sur 1123, Godoy Cruz, Mendoza.

## Generación y validación

- `npm run build`: genera las páginas públicas desde `data/dealership.json`.
- `npm run dev`: servidor local de vista previa.

La demo permanece con `noindex` y bloquea rastreo. No se incluye inventario como vigente: los vehículos y precios del dossier maestro son ejemplos históricos y requieren confirmación de stock. Horarios, redes sociales exactas y correo también están pendientes de confirmación.

## Fuentes

Las referencias públicas consultadas están en `data/dealership.json`. El material detallado de investigación se entregó por separado en el Dossier Maestro de Ozamis Autos y Motos.
